01 — About

The story so far

I started where many engineers do — with curiosity. My journey began exploring Linux, learning how operating systems work at their core, understanding file systems, processes, and the power of the terminal.

That foundation led me deeper. I discovered Red Hat Enterprise Linux and began preparing for the RHCSA certification — a milestone that represents real, hands-on system administration competence.

Alongside that, I built backend systems using NestJS, Prisma, and PostgreSQL. Not just as exercises — real projects like Yamani, a full-stack restaurant management system, and a marketplace platform deployed to production.

My goal is clear: DevOps Engineer and Cloud Infrastructure Specialist. Every tool I learn, every system I build, every deployment I debug moves me closer to that target.
