# Developer Portfolio

A single-page personal portfolio presenting software engineering skills, selected work, learning milestones, and contact information.

## ✨ Page sections

- Hero introduction and availability message
- About and skills sections
- Credentials and goals
- Project cards
- Career timeline
- Contact section
- Scroll-triggered visual effects

## 🧰 Technology

| Area | Tools |
|---|---|
| Structure | HTML5 |
| Styling | Embedded CSS, responsive layouts |
| Interaction | Vanilla JavaScript, Intersection Observer |
| Typography | Google Fonts |

## 🚀 Run locally

```powershell
git clone https://github.com/khalidabdullahiesse-hash/khalid-abdullahi-isse-Protifle.git
Set-Location khalid-abdullahi-isse-Protifle
python -m http.server 8000
```

Open <http://localhost:8000>.

## 🗂️ Structure

The portfolio is intentionally contained in one `index.html` file with its CSS and JavaScript embedded.

## 🎯 Skills demonstrated

Responsive layout, semantic page sections, visual hierarchy, CSS animation, and JavaScript viewport interactions.
